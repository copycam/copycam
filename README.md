# CopyCam

Landing page with an interactive demo of CopyCam — point your phone at text, it lands on your computer's clipboard over Wi-Fi.

Ported from the [Claude Design](https://claude.ai/design) prototype at `CopyCam.dc.html` into a standalone React app (Vite).

## Develop

```
npm install
npm run dev
```

## Props

`App` accepts `accentColor` (default `#CFFF3B`), `deviceName` (default `My MacBook`), and `autoSend` (default `false`) to match the original design's configurable props.
